# 🌐 سرفصل‌یاب و داور هوشمند — نسخه‌ی وب (Vercel)

همان برنامه‌ی `app.py`، اما بازنویسی‌شده با **Next.js** تا بتوانید آن را با یک کلیک روی **Vercel** دیپلوی کنید.

> **چرا Gradio روی Vercel کار نمی‌کند؟**
> Gradio به یک سرور دائمی و وب‌سوکت نیاز دارد، در حالی که Vercel فقط توابع سرورلس با محدودیت زمان (۱۰ تا ۶۰ ثانیه) و حجم (۲۵۰ مگابایت) اجرا می‌کند. پس این نسخه با Next.js نوشته شده است.

---

## ⚡ تفاوت‌های کلیدی با نسخه‌ی پایتونی

| موضوع | نسخه‌ی پایتون (Gradio) | این نسخه (Next.js / Vercel) |
| --- | --- | --- |
| محل تبدیل PDF/Word | سرور (PyMuPDF / mammoth) | **داخل مرورگر** (pdf.js / fflate) — فایل آپلود نمی‌شود |
| کلید API | فایل `.env` روی رایانه | **Environment Variable روی Vercel** (هرگز به مرورگر نمی‌رود) |
| محدودیت حجم فایل | ندارد | همان محدودیت ۴٫۵ مگابایتی آپلود ورکسل را هم ندارد، چون آپلودی انجام نمی‌شود |
| متن‌های بلند | حلقه‌ی پایتون | چند درخواست کوتاه از مرورگر (زیر سقف زمانی Vercel) |
| اجرا | `run.bat` | `dev.bat` برای محلی + `deploy.bat` یا اتصال GitHub |

## 🚀 دیپلوی روی Vercel (سه مرحله)

### روش ۱: از همین رایانه با CLI (ساده‌ترین)

1. اول کلید را روی Vercel تنظیم کنید (یک‌بار برای همیشه):

   ```powershell
   cd web
   npx vercel login
   npx vercel link                       # ساخت/اتصال پروژه
   npx vercel env add DEEPSEEK_API_KEY production
   npx vercel env add APP_PASSWORD production    # اختیاری ولی توصیه‌شده
   ```

2. سپس دیپلوی کنید:

   ```powershell
   npx vercel --prod
   ```

   یا فقط `deploy.bat` را دوبار کلیک کنید (پیش از آن متغیرها را در Dashboard بگذارید).

### روش ۲: از GitHub

1. این پوشه (`web`) را در یک ریپازیتوری GitHub بگذارید.
2. در Vercel: **Add New → Project → Import** ریپازیتوری.
3. اگر پوشه‌ی `web` زیرشاخه است، در بخش **Root Directory** عبارت `web` را انتخاب کنید.
4. در **Settings → Environment Variables** این‌ها را اضافه کنید:

   | نام | مقدار | ضروری؟ |
   | --- | --- | --- |
   | `DEEPSEEK_API_KEY` | `sk-...` | ✅ بله |
   | `APP_PASSWORD` | یک رمز دلخواه | ⚠️ توصیه‌ی جدی |
   | `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | اختیاری |
   | `DEEPSEEK_MODEL` | `deepseek-chat` یا `deepseek-reasoner` | اختیاری |

5. **Deploy** را بزنید. تمام! Framework به‌صورت خودکار Next.js تشخیص داده می‌شود و به هیچ تنظیم دیگری نیاز نیست.

> 🔐 **مهم:** اگر `APP_PASSWORD` را خالی بگذارید، هر کسی که آدرس سایت را داشته باشد می‌تواند از اعتبار حساب دیپ‌سیک شما استفاده کند. حتماً یک رمز بگذارید.

## 💻 اجرای محلی

روی `dev.bat` دوبار کلیک کنید، یا در ترمینال:

```powershell
cd web
npm install
npm run dev
```

سپس مرورگر را روی <http://127.0.0.1:3000> باز کنید.

برای اجرای محلی باید فایل `.env.local` وجود داشته باشد (از `.env.local.example` کپی بگیرید):

```ini
DEEPSEEK_API_KEY=sk-...
APP_PASSWORD=
```

> `npm install` به‌طور خودکار فایل `public/pdf.worker.min.mjs` را می‌سازد تا خواندن PDF به اینترنت/CDN وابسته نباشد.

**پیش‌نیاز:** Node.js نسخه‌ی ۲۰ یا بالاتر.

## 🖱 روش استفاده

| مرحله | کار |
| --- | --- |
| ۱ | فایل PDF یا Word را در کادر بنفش بکشید و رها کنید (یا کلیک کنید). |
| ۲ | دکمه‌ی **«۱) تبدیل به Markdown و استخراج سرفصل»** را بزنید. |
| ۳ | در بخش «۲) نتیجه‌ی تبدیل» تب **🔢 سرفصل‌ها** را ببینید (فهرست تودرتوی فصل‌ها و بخش‌ها). |
| ۴ | (اختیاری) در تب **📄 متن Markdown** متن را ویرایش کنید و «به‌روزرسانی سرفصل‌ها» را بزنید. |
| ۵ | مدل، سقف کاراکتر و (در صورت نیاز) رمز دسترسی را در بخش ۳ تنظیم کنید. |
| ۶ | دکمه‌ی **«۲) تحلیل با DeepSeek و گرفتن نمره»** را بزنید و لاگ مرحله‌به‌مرحله را ببینید. |
| ۷ | در تب **⭐ تحلیل و نمره**: نمره‌ی کل، نمره‌ی هر معیار، نقاط قوت/ضعف، پیشنهادها و جمع‌بندی. |
| ۸ | دکمه‌ی **«⬇ دانلود گزارش (Markdown)»** یک فایل `.md` شامل گزارش داور + متن سند می‌سازد. |

معیارهای داوری همان شش معیار نسخه‌ی پایتونی است:
ساختار و سرفصل‌بندی، محتوا و عمق علمی، انسجام و نظم منطقی، نگارش و ویرایش زبانی، ارجاع‌دهی و اصالت، کاربردی‌بودن برای خواننده‌ی هدف.

## 🧠 چطور توکن کم مصرف می‌شود؟

1. **تبدیل به Markdown:** متن خام PDF/Word پر از اطلاعات قالب‌بندی (فونت، موقعیت، جدول‌های تزئینی) است؛ Markdown فقط ساختار مفید را نگه می‌دارد. شکست خط‌های PDF هم ادغام می‌شوند و شماره‌ی صفحه‌ها حذف می‌شوند.
2. **متن کوتاه (پیش‌فرض تا ۶۰٬۰۰۰ کاراکتر):** یک‌جا برای داوری فرستاده می‌شود.
3. **متن بلند (کتاب):** بر اساس مرز سرفصل‌ها به بخش‌ها تقسیم می‌شود، هر بخش جداگانه خلاصه می‌شود و در پایان
   «سرفصل‌ها + خلاصه‌ها» برای داوری نهایی ارسال می‌شود. یعنی به‌جای صدها هزار توکن، چندین هزار توکن.
4. **سقف کاراکتر** را می‌توانید در بخش ۳ بین ۳۰٬۰۰۰ / ۶۰٬۰۰۰ / ۱۰۰٬۰۰۰ تغییر دهید.

```
web/
├── app/
│   ├── api/deepseek/route.js   # واسطه‌ی امن دیپ‌سیک (کلید API فقط این‌جا)
│   ├── layout.js               # چیدمان راست‌چین و متادیتا
│   ├── page.js                 # تمام رابط کاربری
│   └── globals.css             # استایل‌ها (بدون Tailwind)
├── components/
│   ├── OutlineView.js          # نمایش تودرتوی سرفصل‌ها
│   └── ResultView.js           # کارت نمره و معیارها
├── lib/
│   ├── parse.js                # تشخیص نوع فایل و تبدیل به Markdown
│   ├── pdf.js                  # استخراج PDF با pdf.js (در مرورگر)
│   ├── docx.js                 # استخراج Word با fflate + DOMParser
│   ├── headings.js             # استخراج سرفصل + heuristic
│   ├── text.js                 # آمار، برش و تقسیم متن
│   ├── prompts.js              # پرامپت‌ها (عیناً مثل نسخه‌ی پایتون)
│   ├── result.js               # تفسیر و نرمال‌سازی پاسخ مدل
│   └── deepseek-client.js      # گفت‌وگو با مدل + اجرای مراحل تحلیل
├── scripts/copy-pdf-worker.mjs # کپی worker در public (postinstall)
├── public/pdf.worker.min.mjs   # ساخته‌شده توسط postinstall
├── dev.bat                     # اجرای محلی ویندوز
├── deploy.bat                  # دیپلوی روی Vercel
└── .env.local.example          # نمونه‌ی متغیرهای محیطی
```

## 🧯 رفع خطاهای رایج

| پیام / مشکل | راه‌حل |
| --- | --- |
| ⛔ «کلید DEEPSEEK_API_KEY روی سرور تنظیم نشده است» | روی Vercel در Settings → Environment Variables کلید را بگذارید و **دوباره دیپلوی کنید** (`Deployments → Redeploy`). |
| «رمز دسترسی نادرست است» | همان مقداری را وارد کنید که برای `APP_PASSWORD` گذاشته‌اید. |
| «متن استخراج نشد… OCR» | PDF اسکن‌شده (تصویری) است و لایه‌ی متنی ندارد؛ اول با نرم‌افزار OCR (مثل Adobe یا `ocrmypdf`) به PDF متنی تبدیل کنید. |
| «پاسخ دیپ‌سیک طول کشید و مهلت تمام شد» | سقف کاراکتر را کم کنید، تعداد بخش‌ها کمتر شود، یا مدل را روی `deepseek-chat` بگذارید (reasoner کندتر است). |
| «اعتبار حساب دیپ‌سیک کافی نیست (۴۰۲)» | حساب DeepSeek را شارژ کنید. |
| خواندن PDF کند است / worker نمی‌آید | مطمئن شوید فایل `public/pdf.worker.min.mjs` وجود دارد (`npm run postinstall`). اگر نبود، برنامه خودکار از CDN استفاده می‌کند. |
| در Word سرفصل شناسایی نشد | سرفصل‌ها را در Word با سبک **Heading 1/2/3** بزنید؛ یا در تب Markdown دستی `#` بگذارید و «به‌روزرسانی سرفصل‌ها» را بزنید. |
| فایل `.doc` قدیمی | فقط `.docx` پشتیبانی می‌شود؛ در Word با «Save As → .docx» ذخیره کنید. |

## ⚠️ محدودیت‌ها (صادقانه)

- **PDF اسکن‌شده:** بدون OCR متنی استخراج نمی‌شود.
- **PDF چندستونه:** ترتیب خواندن ممکن است درست نباشد (pdf.js سطرها را بر اساس ترتیب جریان متن می‌دهد).
- **نمره‌ی مدل:** نمره‌ی نهایی نظر هوش مصنوعی است، نه داوری رسمی. برای دقت بیشتر مدل `deepseek-reasoner` را انتخاب کنید.
- **سقف ۶۰ ثانیه‌ای توابع Vercel:** هر درخواست جداست، پس مشکلی پیش نمی‌آید؛ اما برای متن‌های خیلی بزرگ تعداد درخواست‌ها زیاد می‌شود (که در بخش ۳ قبل از شروع نمایش داده می‌شود).
- **۱۰ بخش حداکثری:** اگر متن از این بیشتر شود، بخش‌های انتهایی در یک بخش ادغام می‌شوند تا هزینه کنترل شود.
