# 📚 سرفصل‌یاب و داور هوشمند

یک اپلیکیشن **خیلی ساده** که:

1. فایل **Word (.docx)** یا **PDF** (و همچنین `.md` / `.txt`) را می‌گیرد.
2. آن را به **Markdown** تبدیل می‌کند (برای کم‌کردن مصرف توکن) و **سرفصل‌های** آن را در یک بخش جدا نشان می‌دهد.
3. با زدن دکمه‌ی **تحلیل با DeepSeek**، متن را به مدل می‌دهد؛ مدل می‌خواند، **نظر می‌دهد** و **نمره (۰ تا ۱۰۰)** ثبت می‌کند.

---

## ⚡ اجرای سریع در ویندوز

روی فایل **`run.bat`** دوبار کلیک کنید. این فایل به‌طور خودکار:

1. محیط مجازی می‌سازد،
2. کتابخانه‌ها را نصب می‌کند،
3. برنامه را اجرا می‌کند و مرورگر را باز می‌کند.

> اگر `run.bat` باز نشد، در PowerShell همین پوشه این دستورها را بزنید:
> ```powershell
> python -m venv .venv
> .\.venv\Scripts\activate
> pip install -r requirements.txt
> python app.py
> ```

**پیش‌نیاز:** Python نسخه‌ی ۳.۱۰ یا بالاتر.

## 🧠 چطور توکن کم مصرف می‌شود؟

- **تبدیل به Markdown:** متن خام PDF/Word پر از اطلاعات قالب‌بندی است؛ Markdown فقط ساختار مفید را نگه می‌دارد.
- **حالت متن کوتاه (پیش‌فرض تا ۶۰٬۰۰۰ کاراکتر):** Markdown یک‌جا برای داوری ارسال می‌شود.
- **حالت متن بلند (کتاب‌ها):** با مرز سرفصل‌ها به قطعه‌ها تقسیم می‌شود، هر قطعه جداگانه خلاصه می‌شود و سپس
  «سرفصل‌ها + خلاصه‌ها» برای داوری نهایی می‌رود. با این کار هزینه‌ی یک کتاب چند صد صفحه‌ای به یک دهم کاهش می‌یابد.
  (این گزینه را می‌توانید با تیک «صرفه‌جویی توکن» خاموش کنید.)
- **سقف کاراکتر و حداکثر تعداد قطعه‌ها** قابل تنظیم است (نوار لغزنده در برنامه یا فایل `.env`).

---

## ⚙️ تنظیمات (فایل `.env`)

```ini
DEEPSEEK_API_KEY=sk-...            # کلید API دیپ‌سیک
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat       # یا deepseek-reasoner

MAX_DIRECT_CHARS=60000             # سقف ارسال یک‌جا (≈ ۲۰ هزار توکن)
CHUNK_CHARS=35000                  # اندازه‌ی هر قطعه در حالت خلاصه‌سازی
MAX_CHUNKS=12                      # حداکثر تعداد قطعه (کنترل هزینه)
REQUEST_TIMEOUT=300
MAX_RETRIES=2
```

- مدل `deepseek-chat` سریع و ارزان است و برای داوری کافی است.
- مدل `deepseek-reasoner` دقیق‌تر ولی کندتر و گران‌تر است.

## 📁 ساختار پروژه

```
app.py           رابط کاربری (Gradio) — دو دکمه: تبدیل و تحلیل

analyzer.py      اتصال به DeepSeek، خلاصه‌سازی مرحله‌ای، داوری و ساخت نمره
config.py        تنظیمات و خواندن کلید از .env

requirements.txt کتابخانه‌های لازم
run.bat          نصب و اجرای یک‌کلیکی در ویندوز
test.bat         اجرای تست‌ها با یک کلیک در ویندوز
```

## ✅ تست و عیب‌یابی

```powershell
python selftest.py          # تست‌های آفلاین (سریع، بدون هزینه)
python selftest.py --live   # یک درخواست واقعی کوچک به دیپ‌سیک + داوری نمونه
```

> در ویندوز می‌توانید روی **`test.bat`** دوبار کلیک کنید (به‌جای `python selftest.py`).

| مشکل | راه‌حل |
| --- | --- |
| «کلید API نامعتبر است (۴۰۱)» | مقدار `DEEPSEEK_API_KEY` در `.env` را درست کنید یا در کادر رمز برنامه وارد کنید. |
| «اعتبار حساب کافی نیست (۴۰۲)» | حساب دیپ‌سیک شما شارژ ندارد. |
| سرفصل پیدا نشد | فایل با سبک Heading نوشته نشده یا PDF اسکن‌شده است؛ در این حالت متن Markdown را دستی ویرایش کنید (سرفصل‌ها را با `# ` بنویسید). |
| PDF متنی استخراج نمی‌شود | PDF اسکن‌شده (تصویری) است و به OCR نیاز دارد (مثلاً با Adobe Acrobat یا `ocrmypdf`). |
| خطای `mammoth` برای Word | `pip install mammoth` و دوباره تلاش کنید. فقط `.docx` پشتیبانی می‌شود (نه `.doc` قدیم). |

## 🔒 نکته‌ی امنیتی

کلید API در فایل `.env` ذخیره شده و این فایل در `.gitignore` است، پس با Git منتشر نمی‌شود.
اگر این کلید را جایی به اشتراک گذاشته‌اید، از پنل دیپ‌سیک آن را **باطل و کلید جدید بسازید**.

## 🌐 نسخه‌ی وب برای دیپلوی روی Vercel

در پوشه‌ی **`web/`** همین برنامه با **Next.js** بازنویسی شده تا بتوانید آن را روی **Vercel** بالا بیاورید:

```powershell
cd web
npx vercel login
npx vercel env add DEEPSEEK_API_KEY production
npx vercel env add APP_PASSWORD production      # توصیه‌شده: رمز دسترسی سایت
npx vercel --prod
```

تفاوت‌های مهم با این نسخه (پایتونی):

- فایل PDF/Word **داخل مرورگر** به Markdown تبدیل می‌شود، پس نه به Python نیاز دارد و نه به آپلود فایل.
- کلید API در **متغیرهای محیطی Vercel** می‌ماند و هرگز به مرورگر نمی‌رود؛ یک رمز دسترسی اختیاری هم دارد.
- بقیه‌ی منطق (پرامپت‌ها، شش معیار، خلاصه‌سازی مرحله‌ای و نمره‌دهی) عیناً همان است.

راهنمای کامل: [`web/README.md`](web/README.md) — برای اجرای محلی روی `web/dev.bat` و برای دیپلوی روی `web/deploy.bat` دوبار کلیک کنید.
